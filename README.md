# Discord media downloader bot 🎯
A discord media downloader from TikTok &amp; Instagram
## How to get bot ready
1. Type in cmd
```
pip install requirements.txt 
```
2. Open bot.py and scroll down to
```
TOKEN = os.environ.get('DISCORD_TOKEN', 'YOUR_BOT_TOKEN')
bot.run(TOKEN)
```
Change ``YOUR_BOT_TOKEN`` With your bot token from the developer portal

## How to get Cookies
Use fake TikTok & Instagram account
sign in and add this browser extention ``Get cookies.txt LOCALLY`` 
Then click extract cookie or copy and change bot cookies content TikTok cookies in ``tiktok_cookies.txt`` & Instagram cookies in ``insta_cookies.txt``

## Finally
Type 
```
python bot.py
```
Now you can share Insta & TikTok Posts In Discord.
